## 2. 데이터 보안 답변

- 데이터 수집·공유: **수집함**, 전송 중 암호화 **예**, 삭제 요청 방법 **제공**
  (앱 내 회원 탈퇴 + 계정 삭제 URL `https://suvisdev.cloud/gildle/account-deletion`)
- 제3자 **공유 없음** — 카카오(장소 검색·로그인)·네이버(지도)·Firebase(푸시)는 우리를 대신해
  처리하는 서비스 제공업체라 Google 정의상 "공유"가 아니다.

| 데이터 유형 | 수집 | 필수/선택 | 목적 | 비고 |
|------|------|------|------|------|
| 위치 > 정확한 위치 | 예 | 선택(산책 기록 저장 시) | 앱 기능 | 계정에 연결, 기록 삭제·탈퇴 시 삭제. 경로 계산 좌표는 저장 안 함 |
| 개인 정보 > 이메일 주소 | 예 | 선택(로그인 시) | 계정 관리 | |
| 개인 정보 > 사용자 ID | 예 | 선택 | 계정 관리 | 카카오 계정 식별자 |

## 5. 테스트 트랙

1. **내부 테스트**: 테스터 목록(본인 Gmail) → 새 버전 → Play 앱 서명 "Google에서 관리" 수락 →
   `gildle-release-20260928.aab` 업로드 → 출시 노트 "첫 내부 테스트" → 테스터 링크로 설치.
2. 설치 직후 **카카오 로그인 확인**. 실패하면 Play Console > 테스트 및 출시 > 앱 무결성 >
   앱 서명 키 인증서의 SHA-1을 카카오 키 해시로 변환해 Kakao Developers > 앱 > 플랫폼 > Android
   키 해시에 추가한다:
   `echo <SHA1 콜론 포함> | xxd -r -p | openssl base64`
   (업로드 키 SHA-1 `48:FF:D5:6E:…:11:E5`와 다르다 — Play가 다시 서명하기 때문.)
   이메일 로그인·지도는 키 해시와 무관.
3. **비공개 테스트**: 국가 대한민국, 테스터 12명 이상(이메일 목록 또는 Google 그룹) →
   참여 링크 공유 → **14일 연속** 설치 유지 → 프로덕션 액세스 신청.
