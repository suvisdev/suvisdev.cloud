## 운영·인프라 전제

- 지금은 suvisdev 백엔드 안의 앱이다(별도 서버 비용 0). 고객이 늘어 독립 서버가 필요해지면 월 5만 원 상한 안에서 검토한다.
- 토큰 재사용 기록과 속도 창은 프로세스 메모리 — backend `replicas: 1` 전제. 파드를 늘리면 Redis로 옮긴다.
- 티켓 오픈일 폭주 때 suvisdev 다른 앱과 같은 파드를 쓴다는 점이 위험하다. 첫 대형 오픈 전에 부하를 측정한다.
