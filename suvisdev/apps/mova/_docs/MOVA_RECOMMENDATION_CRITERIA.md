# mova 추천 기준 (SSOT)

> 2026-09-28 사용자 결정. "무엇을 좋은 추천으로 보나"를 모델(LoRA·Gemini 교사)의 재량이 아니라
> 이 문서로 정한다. 후보 점수(코드) · 심판 루브릭(학습 데이터) · 평가 지표가 모두 이 기준을 따른다.
> 기존 불변식(카탈로그 한정·연도/국가 하드 필터·기추천 dedup·정직 문구)은 `.claude/rules/mova-chat.md`
> §2~4가 SSOT이며 이 문서는 그 위에 **순위 기준**만 더한다.

## 1. 왜 필요한가

- 현행: 후보 16편(태그 실매칭 ≤10 + 시맨틱 보충, 없으면 인기작) → **LoRA 2.4B가 3편을 고른다**.
  선택 기준은 프롬프트에 "카탈로그 안에서"뿐이고, 품질·다양성·볼 수 있음은 어디에도 없다.
- 학습도 같은 공백을 물려받는다 — 교사(Gemini) 답·RS 심판 루브릭(그라운딩·말투·hook·정직성 4줄)이
  기준의 전부라 "Gemini 취향"이 곧 기준이 된다. 후보가 나쁘면 교사도 나쁜 걸 고른다.
- 기준선(§5)에서 분위기 질의가 조건과 무관한 최신작으로 채워지는 문제가 드러났다.

## 2. 순위 기준 (위가 우선)

| # | 기준 | 결정값 |
|---|------|--------|
| 1 | **조건 적합** | 장르·분위기·배우·연도. **요청 단어가 제목에만 겹치는 작품은 후보 제외**(태그·줄거리 근거 필요) |
| 2 | **품질 하한** | TMDB `vote_count` **30 미만은 뒤로**(제외 아님 — 숨은 작품 보존) |
| 3 | **다양성** | 3편 안에 같은 시리즈·같은 연대 몰림 금지(MMR식 감점) |
| 4 | **볼 수 있음** | 상영 중·OTT 있음은 **가산점만**(없어도 추천함) |
| 5 | **개인 취향** | 로그인 사용자 taste vector 가산(현행 순서 재정렬을 점수로 편입) |
| 6 | **최신성** | 조건 없을 때 최근 15년 **약한** 가산 |

## 3. 3편 구성 — 역할 나누기

한 응답의 3편은 역할이 다르다: **가장 잘 맞는 1편 + 대중적인 1편(투표 수 상위) + 숨은 작품 1편**
(적합 상위권 중 투표 수는 적지만 평점 높은 쪽). 후보가 부족하면 역할보다 적합을 우선하고,
억지로 채우지 않는다(정직 규칙 유지).

## 4. 반복 요청 · "더 보기"

- 순위는 코드가 한 번 넓게(후보 16 → 50편) 매긴다. LLM은 상위 3편 소개·hook만 쓴다.
- 같은 요청 반복·"더 보여줘"는 **순위의 다음 작품**을 보여 준다(LLM 없이 즉시). 바닥나면 조건을
  조금 넓혀 새로 찾는다 — "새 작품이 없어요" 안내는 그 뒤에만(09-28 대화 38: 같은 요청 4회 반복).

## 5. 측정 — `scripts/eval_chat_queries.py` 카드 품질 지표

PASS/FAIL(결정론 위반)과 별개로 집계한다. `--catalog`(운영 DB 추출 TSV)로 투표 수를 채우고
`--save`로 전후 비교 파일을 남긴다.

| 지표 | 뜻 |
|------|----|
| `zero_card_queries` | 카드 0장 질의 수 |
| `series_dup_queries` | 3편에 같은 시리즈가 겹친 질의 수(제목 부제·번호 제거 비교) |
| `low_vote_cards` | 투표 30 미만 카드 수 |
| `available_cards` | `platform`이 있는 카드 수 |
| `title_overlap_cards` | 질의 어절이 제목 어절과 겹친 카드(표면 매칭 의심 — 사람이 확인) |
| `repeated_titles` | **서로 다른 질의 3개 이상**에 나온 작품 수(조건과 무관한 채움 의심) |

**기준선(2026-09-28, 운영 v5, 28질의)** — `~/datasets/mova_eval/baseline_20260928.json`

| 지표 | 값 |
|------|----|
| PASS | 28/28 |
| cards / zero_card_queries | 73 / 1 |
| series_dup_queries | 1 (마동석 액션: 범죄도시·범죄도시 3) |
| low_vote_cards | 1 (위대한 계춘빈) |
| available_cards | 35/73 |
| title_overlap_cards | 1 (뉴욕 배경 → 고스트버스터즈: 오싹한 뉴욕) |
| **repeated_titles** | **4** — 캔터빌의 유령·마운틴헤드(각 4질의), 캠프 락 3·180(각 3질의) |

핵심 문제는 마지막 줄이다: "비 오는 날"·"기분 좋아지는"·"잔잔한"·"소름 돋는 반전"·"조선시대 사극"에
같은 2025~2026년작이 반복된다. 분위기 질의가 태그 실매칭 없이 시맨틱 저유사 히트/최신 인기작으로
채워진다는 뜻이며, 기존 PASS 판정으로는 보이지 않았다.

## 7. 외부 데이터 검토 결과 (09-28)

- **MovieLens Tag Genome 2021**(CC BY-NC 3.0 — mova는 TMDB 때문에 어차피 비상업): 태그는 대체로 정확
  (비포 선라이즈→dialogue·train, 컨저링→scary·creepy)하나 잡음 있음. 카탈로그 연결 **805/3908편(21%)**,
  전부 2021년 이전. 분위기 태그(atmospheric·feel-good·heartwarming·melancholic·tense·travel)는 있으나
  "rainy day"는 없음. **보류** — 줄거리 임베딩으로 신작 추정 시 새 정보가 적을 수 있어, 2단계 뒤
  분위기 질의 10개 전후 비교로 채택 여부를 정한다. 추린 점수 `~/datasets/movielens/genome_catalog_scores.tsv`.
- **ReDial**(CC BY 4.0): 카탈로그 연결 821편, 7.8B 번역 시범에서 화자·뜻 뒤틀림 + 원본 품질 낮음 → **제외**.
- **KMDb**(한국영상자료원 API): 한국 영화 키워드·줄거리 보강용 — API 키 발급 후 나중에.
