# mova 추천 기준 (SSOT)

> 2026-09-28 사용자 결정. "무엇을 좋은 추천으로 보나"를 모델(LoRA·Gemini 교사)의 재량이 아니라
> 이 문서로 정한다. 후보 점수(코드) · 심판 루브릭(학습 데이터) · 평가 지표가 모두 이 기준을 따른다.
> 기존 불변식(카탈로그 한정·연도/국가 하드 필터·기추천 dedup·정직 문구)은 `.claude/rules/mova-chat.md`
> §2~4가 SSOT이며 이 문서는 그 위에 **순위 기준**만 더한다.

## 1. 왜 필요한가

- 현행: 후보 16편(태그 실매칭 ≤10 + 시맨틱 보충, 없으면 인기작) → **LoRA 2.4B가 3편을 고른다**.
  선택 기준은 프롬프트에 "카탈로그 안에서"뿐이고, 품질·다양성·볼 수 있음은 어디에도 없다.
- 학습도 같은 공백을 물려받는다 — 교사(Gemini) 답·RS 심판 루브릭(그라운딩·말투·hook·정직성 4줄)이
  기준의 전부라 "Gemini 취향"이 곧 기준이 된다. 후보가 나쁘면 교사도 나쁜 걸 고른다.
- 기준선(§5)에서 분위기 질의가 조건과 무관한 최신작으로 채워지는 문제가 드러났다.

## 2. 순위 기준 (위가 우선)

| # | 기준 | 결정값 |
|---|------|--------|
| 1 | **조건 적합** | 장르·분위기·배우·연도. **요청 단어가 제목에만 겹치는 작품은 후보 제외**(태그·줄거리 근거 필요) |
| 2 | **품질 하한** | TMDB `vote_count` 30 이상이 **5편 이상이면 30 미만 제외, 모자라면 뒤로**(09-28 밤 사용자 결정으로 강화 — "뒤로만"은 효과 없음). 숨은 작품은 §3 역할로 따로 살린다 |
| 3 | **다양성** | 3편 안에 같은 시리즈 금지 — 후보에서 시리즈당 앞선 1편만(`series_key`, 09-28 밤). "○○ 시리즈"·프랜차이즈 제목 매칭 요청은 예외. 연대 몰림은 연대 지정 질의와 충돌·지표 없음으로 보류 |
| 4 | **볼 수 있음** | 상영 중·OTT 있음은 **가산점만**(없어도 추천함) |
| 5 | **개인 취향** | 로그인 사용자 taste vector 가산(현행 순서 재정렬을 점수로 편입) |
| 6 | **최신성** | 조건 없을 때 최근 15년 **약한** 가산 |

## 3. 3편 구성 — 역할 나누기

한 응답의 3편은 역할이 다르다: **가장 잘 맞는 1편 + 대중적인 1편(투표 수 상위) + 숨은 작품 1편**
(적합 상위권 중 투표 수는 적지만 평점 높은 쪽). 후보가 부족하면 역할보다 적합을 우선하고,
억지로 채우지 않는다(정직 규칙 유지).

## 4. 반복 요청 · "더 보기"

- 순위는 코드가 한 번 넓게(후보 16 → 50편) 매긴다. LLM은 상위 3편 소개·hook만 쓴다.
- 같은 요청 반복·"더 보여줘"는 **순위의 다음 작품**을 보여 준다(LLM 없이 즉시). 바닥나면 조건을
  조금 넓혀 새로 찾는다 — "새 작품이 없어요" 안내는 그 뒤에만(09-28 대화 38: 같은 요청 4회 반복).

## 5. 측정 — `scripts/eval_chat_queries.py` 카드 품질 지표

PASS/FAIL(결정론 위반)과 별개로 집계한다. `--catalog`(운영 DB 추출 TSV)로 투표 수를 채우고
`--save`로 전후 비교 파일을 남긴다.

| 지표 | 뜻 |
|------|----|
| `zero_card_queries` | 카드 0장 질의 수 |
| `series_dup_queries` | 3편에 같은 시리즈가 겹친 질의 수(제목 부제·번호 제거 비교) |
| `low_vote_cards` | 투표 30 미만 카드 수 |
| `available_cards` | `platform`이 있는 카드 수 |
| `title_overlap_cards` | 질의 어절이 제목 어절과 겹친 카드(표면 매칭 의심 — 사람이 확인) |
| `repeated_titles` | **서로 다른 질의 3개 이상**에 나온 작품 수(조건과 무관한 채움 의심) |

**기준선(2026-09-28, 운영 v5, 28질의)** — `~/datasets/mova_eval/baseline_20260928.json`

| 지표 | 값 |
|------|----|
| PASS | 28/28 |
| cards / zero_card_queries | 73 / 1 |
| series_dup_queries | 1 (마동석 액션: 범죄도시·범죄도시 3) |
| low_vote_cards | 1 (위대한 계춘빈) |
| available_cards | 35/73 |
| title_overlap_cards | 1 (뉴욕 배경 → 고스트버스터즈: 오싹한 뉴욕) |
| **repeated_titles** | **4** — 캔터빌의 유령·마운틴헤드(각 4질의), 캠프 락 3·180(각 3질의) |

핵심 문제는 마지막 줄이다: "비 오는 날"·"기분 좋아지는"·"잔잔한"·"소름 돋는 반전"·"조선시대 사극"에
같은 2025~2026년작이 반복된다. 분위기 질의가 태그 실매칭 없이 시맨틱 저유사 히트/최신 인기작으로
채워진다는 뜻이며, 기존 PASS 판정으로는 보이지 않았다.

**2단계 선행 수정 후(2026-09-28 밤, 불용어)** — `~/datasets/mova_eval/stopword_20260928.json`

반복 작품 4편과 투표 미달 카드(위대한 계춘빈)는 **전부 태그 "TV 영화" 10편**이었다. 원인은 순위 기준 부재가
아니라 키워드 버그였다 — 모든 질의 키워드에 "영화"가 남아 태그 `ILIKE '%영화%'`가 "TV 영화"를 실매칭으로
물어왔고, 태그 후보가 최신순으로 앞 10자리를 차지했다. `_fallback_raw` 토큰에 불용어 적용으로 해결.

| 지표 | 기준선 | 수정 후 |
|------|--------|---------|
| PASS | 28/28 | 28/28 (멀티턴 17/17) |
| cards / zero_card_queries | 73 / 1 | 81 / 1 |
| series_dup_queries | 1 | 1 |
| low_vote_cards | 1 | **6** |
| available_cards | 35/73 | 38/81 |
| title_overlap_cards | 1 | 1 |
| **repeated_titles** | **4** | **0** |

바뀐 14질의 중 법정·정치 스릴러·복수극·춤·직장인·비 오는 날 등은 조건에 맞는 작품으로 바뀌었다. 새 문제는
`low_vote_cards` 1→6: 분위기 질의가 이제 시맨틱(RAG) 히트로 채워지는데 이 경로엔 투표 수 정렬이 없다
(춘색한녀·흑귀·바라만 본다 등). **2단계의 남은 일 1순위는 §2-2 품질 하한**(후보에 vote_count를 실어 30 미만을
뒤로)이고, "조용한 가족"(잔잔한)·"비와 당신의 이야기"(비 오는 날) 같은 시맨틱 제목 근접은 §2-1 대상이다.

**품질 하한 후(2026-09-28 밤)** — `qualityfloor2_20260928.json`. 시맨틱 히트에 연도·장르·줄거리·투표 수도
채운다(`get_catalog_items` — 전엔 "연도 미상"·줄거리 없이 제목만 프롬프트에 실렸다).

| 지표 | 불용어 수정 후 | 뒤로만(1차) | 충분하면 제외(최종) |
|------|----------------|-------------|---------------------|
| PASS / 멀티턴 | 28/28 · 17/17 | 28/28 · 17/17 | 28/28 · 17/17 |
| low_vote_cards | 6 | 7 | **5** |
| repeated_titles | 0 | 0 | 0 |
| series_dup / title_overlap | 1 / 1 | 2 / 2 | 2 / 2 |

"뒤로만"이 안 통한 이유: 분위기 질의는 시맨틱 후보 8편이 전부 프롬프트(앞 12편)에 실리고 LoRA가 뒤쪽도 고른다.
남은 5장(사극·춤·비 오는 날·기분 좋아지는)은 **후보 8편 중 투표 30 이상이 3~4편뿐**이라 규칙상 "뒤로"가 적용된
경우다(bge-m3 시뮬레이션: k=8 → 3~4편, k=16 → 5~9편). 다음 수는 시맨틱 풀 확장(k 8→16~24)인데, 유사도 0.47~0.57
꼬리에 무관작(비 오는 날→나잇 & 데이, 춤→베놈: 라스트 댄스)이 섞이는 트레이드오프가 있다. series_dup 1→2(형사물:
나쁜 녀석들 1·포에버)는 §2-3 다양성의 몫.

**다양성 후(2026-09-28 밤)** — `diversity_20260928.json`: series_dup **2→0**, low_vote 5→3, 멀티턴 17/17, 단일턴
27/28 — FAIL 1건 "기분 좋아지는 영화"는 LoRA가 후보 8편에서 0편 → Gemini 폴백 503(재실행 3/3 정상). 이 질의는 현재
파드에서 LoRA 0편이 4/4(전부 Gemini가 구제)라 LoRA 약점으로 관찰 중 — 시맨틱 후보에 줄거리를 채운 뒤 생긴 것인지는
이전 파드 로그가 없어 미확인.
→ **원인 규명·수정(같은 밤)**: LoRA 0편이 아니라 **JSON 파싱 실패**였다. 저장된 원문(`chat.reply`, 300자에서 잘려 저장)이
후보를 순서대로 4편 넘게 나열 중이었고, 토큰 계산상 6편이면 `max_new_tokens=256`을 넘는다. 잘린 응답에서 완결 pick만 살리게
파서를 보강 → 배포 후 하네스 **28/28 · 17/17**, 도중 실제 1회 "pick 6개 복구", 파싱 실패·폴백 0건. 줄거리 채우기와의
인과는 없음(재현 스크립트로 A·B 프롬프트 모두 16/16 정상 JSON — 과다 나열은 시점에 따라 나타남).

## 6. 단계

| 단계 | 내용 | 재학습 | 상태 |
