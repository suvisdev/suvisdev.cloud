# SPEC — 목표·완료 기준

CLAUDE.md가 `@`로 매 세션 불러온다. **목표나 완료 기준이 바뀔 때만** 고친다(사용자 결정이 근거).
지금 어디까지 왔는지는 `STATE.md`, 지난 일은 `WORK_LOG_<앱>.md`에 쓴다. 짧게 유지한다(한 앱 5줄 안팎).

## 공통
- 무료·단순이 먼저(유료 API·인프라 안 씀, 과설계 안 함). 운영은 노트북 한 대(ADR-0008).
- 완료는 실제로 돌려 본 결과로만 말한다. 코드 변경은 검증 → Codex OK → CI → 머지까지가 한 단위.
