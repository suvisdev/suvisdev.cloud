# 실패 → 극복 (LESSONS)

작업 일지(`WORK_LOG_*.md`)는 "그날 있었던 일"의 상세 기록이라 다 읽을 수 없다. 이 파일은 그 위의
**압축 층**이다 — 잘못됐던 것 하나에 한 줄: 증상 → 원인 → 극복. 근거는 `근거` 열의 워크로그 날짜.
세션 끝에 실패를 해결(또는 미결로 확정)했으면 여기에 한 줄을 남긴다(루트 CLAUDE.md "작업 일지" 규칙).
