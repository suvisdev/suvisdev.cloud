# ADR-0001. 모든 프로젝트는 무료 기반

> **상태: 확정 · 2026-11-06**

## 문제

새 기능마다 유료 API나 모델을 후보로 올리면, 성능은 좋아도 사용자가 계속 운영할 수 없다.

## 결정

모델·서비스·인프라는 로컬(Ollama 등)이나 확실히 무료인 것을 쓴다. 과금될 수 있는 것은 쓰기 전에 비용을 밝히고 허락을 받는다.

## 배제한 대안

- 성능 우선으로 유료 API 사용: 사용자 말 "내가 돈이 없거든". 운영을 이어 갈 수 없다.

## 결과·확인

- 스킬 라우팅 모델 선택에 바로 적용했다(ADR-0002).
