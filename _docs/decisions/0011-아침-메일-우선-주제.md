# ADR-0011: 아침 메일은 새 기술 → 대기업 적용 → 한국·해외 차이 순으로 먼저 보낸다

상태: 확정 (2026-11-13, 사용자 결정)

## 문제

- 아침 메일은 학습 가치·화제·출처 순으로만 정렬했다. 사용자는 새 기술, 대기업이 지금 쓰는 기술, 한국과 해외의 차이를 먼저 받기를 원한다.
- 대기업 적용 사례와 국내외 비교 글은 분류 기준상 industry로 빠질 수 있었다.

## 결정

- 분류 모델이 우선 주제 `focus`(new_tech·bigtech·korea_global·none)를 함께 답한다. 정렬은 우선 주제 → 학습 가치 → 화제 → 출처.
- bigtech·korea_global 글은 label이 industry여도 메일 후보로 받는다.

## 배제한 대안

- 회사 이름 키워드로 대기업 글 판정: 이름만 나온 인사·투자 글까지 올라오고, 모델 판단을 코드 규칙으로 덮는 일이다(CLAUDE.md §5).
- 주제별 칸을 나눠 정원 배정: 주제마다 글이 없는 날이 많아 칸이 비거나 질 낮은 글로 채워진다.

## 결과·확인

- 실제 글 60건 시험은 `WORK_LOG_MAINPAGE.md` 11-13. bigtech 판정은 아직 약하다 — 틀린 사례는 정답셋·학습 데이터로 모은다.
