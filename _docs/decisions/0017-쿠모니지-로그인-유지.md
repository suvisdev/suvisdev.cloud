# ADR-0017: 쿠모니지는 싱글도 로그인 필수, 로그인은 30일 동안 안 쓸 때만 풀린다

상태: 확정 (2026-11-21, 사용자 결정)

## 문제

- 계획 B(계정)는 멀티에만 로그인을 요구했고, 로그인 유지는 SECURITY.md 시작값(유휴 7일·절대 30일)이었다. 그러면 매일 하는 사람도 30일마다 다시 로그인해야 한다.

## 결정

- **싱글도 로그인해야 쓸 수 있다.** 앱을 켜면 저장된 세션으로 자동 로그인, 없거나 만료면 로그인 화면.
- **리프레시 토큰은 유휴 30일 만료만 두고 절대 만료는 없앤다**(일반 게임 방식). 로그아웃·비밀번호 변경·재설정·탈퇴·보호 요청·리프레시 재사용 탐지 때는 지금처럼 즉시 폐기.
- 민감 작업의 5분 재인증·MFA는 그대로라 오래 유지된 세션만으로 계정을 바꿀 수 없다. 기기 분실은 설정의 기기 목록·모든 기기 로그아웃으로 끊는다.
- SECURITY.md 2절 "토큰 검증·회전" 수치를 이 값으로 고친다(문서는 자체 설계 원칙이라 법적 기준이 아님).

## 배제한 대안

- SECURITY.md 그대로(7일·30일): 매일 하는 사람도 30일마다 재로그인.
- 유휴 30일·절대 90일: 사용자가 "보통 게임처럼"을 택함.
- 만료 없음: 버려진 기기의 세션이 영원히 살아 있게 됨.

## 결과·확인

- 계획 B(`kumoniji/_docs/plans/2026-11-21-B-accounts.md`) 반영. 구현·테스트는 계획 B Task 6.
