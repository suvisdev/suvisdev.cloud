# ADR-0002. 스킬 라우팅은 규칙 먼저, 무료 로컬 모델로 보완

> **상태: 확정 · 2026-11-06**
> 관련: ADR-0001 · ADR-0003

## 문제

스킬 적용을 모델 판단에만 맡기면 빠지고, 정규식만 쓰면 "로그인 눌러도 반응이 없어"처럼 단어가 다른 요청을 놓친다.

## 결정

- 프롬프트·파일 경로·명령·검사 실패는 코드로 먼저 판정한다(`.claude/skill-routes.json`).
- 규칙에 안 걸린 요청만 Ollama EXAONE 7.8B가 의도로 판단한다(`.claude/skill-intent.json`).
- 모델이 없거나 5초를 넘기면 판단 없이 진행하고, 목록 밖 이름은 코드에서 버린다.
- 서브에이전트를 띄우는 스킬은 사용자가 명시적으로 말했을 때만 연결한다.

## 배제한 대안

직접 만든 시험 문장 기준 측정이며, 운영 성능을 보장하지 않는다.

| 후보 | 의도 적중 | 일반 문장 통과 | 중간 지연 | 버린 이유 |
|---|---|---|---|---|
| 정규식만 | 0/25 | 6/6 | 0초 | 규칙 단어를 뺀 시험에서 전부 놓침 |
| Haiku 5.5 | 25/25 | 6/6 | 3.59초 | 요금제 사용량 소모(ADR-0001) |
| EXAONE 2.4B | 14/25 | 0/6 | 0.26초 | 일반 문장을 전부 오탐 |
| bge-m3 예시 검색 | 새 문장 15/18 | 4/5 | 0.15초 | EXAONE보다 낮음 |

## 결과·확인

- 채택안(예시를 넣은 EXAONE 7.8B): 새 문장 17/18, 일반 5/5, 중간 0.35초.
- 노트북 서버를 끄면 Ollama가 없어 규칙만 동작한다.
