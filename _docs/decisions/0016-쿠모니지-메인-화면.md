# ADR-0016: 쿠모니지 메인 화면은 싱글·멀티·게임 방법·옵션, 종료 버튼은 두지 않는다

상태: 확정 (2026-11-21, 사용자 선택)

## 문제

- 앱이 바로 게임 화면으로 시작했다. 모드 선택·설정을 둘 첫 화면이 필요하다. 사용자 초안은 싱글·멀티·옵션·종료.

## 결정

- 메인 화면 버튼은 **싱글 · 멀티(2단계 전까지 '준비 중' 비활성) · 게임 방법 · 옵션**.
- **종료 버튼은 두지 않는다.** 웹은 페이지가 스스로 탭을 닫을 수 없고, iOS는 앱 안 종료 버튼을 권하지 않아 심사 거절 사유가 될 수 있다.
- 옵션은 언어 · 배경음악 · 효과음 · 진동. 배경음악·효과음은 소리가 들어올 때까지 음량 값만 저장한다.

## 배제한 대안

- 종료 버튼을 안드로이드에서만 보이기: 플랫폼마다 화면이 달라지고, 안드로이드도 뒤로 가기로 나갈 수 있다.
- 옵션에 언어만: 사용자가 기본 설정(음량·진동)을 함께 원했다.

## 결과·확인

- 앱 테스트 17개, 로컬 웹 캡처. 상세는 `WORK_LOG_MAINPAGE.md` 11-21.
