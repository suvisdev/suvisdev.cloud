# ADR-0007: 서버 전체 끄기와 노트북 바로가기 켜기

상태: 확정 (2026-11-06)

## 문제

기존 "노트북 서버 끄기"는 집컴이 이어받아 사이트가 계속 돈다. 사용자는 어디서도 돌지 않게 끄는 버튼을 원했다. 전부 끄면 백엔드와 로그인도 멈춰 어드민으로 다시 켤 수 없다.

## 결정

- 어드민에 "전체 끄기(집컴까지)"를 추가한다. 노트북 에이전트가 집컴을 SSH로 끄고, DB·Redis를 맨 나중에 끈다. 재부팅해도 꺼진 채 남는다.
- 집컴은 서비스만 끄고 윈도우는 켜 둔다.
- 다시 켜기는 노트북 바탕화면 바로가기로 한다. 노트북이 켜져 있어야 한다.

## 배제한 대안

- 집컴 윈도우까지 종료: 집에서 전원 버튼을 눌러야 켤 수 있고 그 전에는 사이트를 살릴 수 없다.
- 폰 켜기 페이지(Tailscale): 밖에서도 켤 수 있지만 만들고 지킬 것이 늘어난다. 필요해지면 추가한다.
- 켜기 전용 백엔드를 살려 두기: "어디서도 안 돈다"는 요구와 어긋난다.

## 결과·확인
