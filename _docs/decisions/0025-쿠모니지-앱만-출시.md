# ADR-0025: 쿠모니지는 앱(안드로이드 → 아이폰)만 출시한다

상태: 확정 (2026-11-26 사용자 결정)

## 문제

- SPEC의 출시 순서는 웹(kumoniji.suvisdev.cloud) → 안드로이드 → 아이폰이었다. 앱이 가로 고정(11-25)이 되고 웹도 가로·세로 안내를 붙이면서, 웹을 제품으로 낼지 앱만 낼지가 남아 있었다.

## 결정

- 출시 대상은 앱만이다(안드로이드 → 아이폰). 웹은 출시·홍보하지 않는다.
- 웹 주소는 지금처럼 남겨 둔다 — 개발·시험 화면으로 쓴다(gildle과 같은 방식). 내릴지는 앱 출시 뒤 다시 정한다.
- 웹에서만 생기는 문제(새로고침 속도·쿠키 경합 등)는 앱에 영향이 없으면 우선순위를 낮춘다.
- 같은 날 정한 것: 일본어 제목은 따로 만들지 않고 영어 제목으로 통일한다.

## 배제한 대안

- 웹 먼저 출시: 가로 고정 게임이라 휴대폰 브라우저에서 보기 어렵고, 웹보드게임 규제·결제도 앱 스토어 쪽이 단순하다.
- 웹을 바로 내림: 개발 중 시험이 앱 빌드보다 빠르고, 이미 운영 중인 서버·로그인을 같이 쓰므로 남겨 둔다.

## 결과·확인

- SPEC 쿠모니지 목표 줄을 "앱만(안드로이드 → 아이폰)"으로 고쳤다.
