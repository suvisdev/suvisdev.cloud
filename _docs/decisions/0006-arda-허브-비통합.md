# ADR-0006. Arda는 허브에 합치지 않는다

> **상태: 확정 · 2026-11-06**

## 문제

news처럼 Arda도 `suvisdev` 허브 앱으로 합칠 수 있는지 사용자가 물었다.

## 결정

합치지 않는다. Arda는 `/mnt/c/Team Seuk/Arda`의 별도 저장소로 두고, 필요할 때 읽기만 한다.

## 배제한 대안

- `suvisdev/apps/`로 이식: Seuk-Team의 팀 저장소(커밋한 사람 7명, 파일 852개)이고 백엔드·프론트·모바일·AI·인프라를 갖춘 별도 제품이다. 코드 수정 금지 지시(해커톤 종료 시까지)와도 부딪힌다.

## 결과·확인

- news는 이미 허브 앱이다(`suvisdev/apps/news`, `suvis/app/news`).
