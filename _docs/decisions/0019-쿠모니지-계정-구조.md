# ADR-0019: 쿠모니지 계정은 게임 서버 안에, 상태는 별도 Postgres에만 둔다

상태: 확정 (2026-11-21, 사용자 결정 + 구현 중 결정)

## 문제

- 멀티 모드(친구방·자동 매칭)와 싱글 모두 로그인이 필요하다(ADR-0017). SECURITY.md 1·2절(검증 1~13)을 지키는 계정 기능을 어디에 어떻게 둘지 정해야 했다.

## 결정

- **쿠모니지 서버 안의 `accounts/` 패키지**로 만든다. 파드 하나를 유지한다.
- **상태는 새 Postgres 컨테이너 `kumoniji-db`에만 둔다**(사용자 결정).
  - 위치는 노트북 도커 :5434, 볼륨 `kumoniji_db_data`.
  - 시도 제한·세션 폐기도 여기에 둔다(SECURITY 12: Redis 단독 금지).
  - SQL은 psycopg 3로 직접 쓰고, 마이그레이션은 번호 붙은 `.sql`을 시작 때 advisory lock 아래 적용한다.
- **웹은 `__Host-` 쿠키 + Origin 확인 + 이중 제출 CSRF**를 쓴다. 앱은 `X-Kumoniji-Client: app` 머리글과 Bearer를 쓰고, 쿠키를 쓰지 않으므로 CSRF 대상이 아니다.
- **메일 링크는 앱 화면이 연다**(`/verify`·`/reset`·`/email`·`/protect`). GET은 표시만 하고 POST가 토큰을 쓴다. 이렇게 해야 메일 스캐너가 링크를 열어도 토큰이 닳지 않는다.
- **보호 링크("내가 아니에요")는 인증 버전을 보지 않는다.** 다른 토큰과 다른 예외다.
  - 탈취자가 비밀번호를 바꿔도 주인이 받은 신고 링크가 살아 있어야 한다.
  - 새 알림이 와도 이전 보호 링크를 무효로 만들지 않는다.
  - 링크를 쓰면 계정을 잠그기만 하고, 로그인·복원 권한은 주지 않는다.
- **구글 계정은 같은 이메일의 자체 계정과 자동으로 합치지 않는다.** 이메일 칸을 비운 새 계정을 만들고, 연결은 로그인한 뒤 설정에서 한다.
- **CanvasKit은 자체 호스팅한다**(`--no-web-resources-cdn`). 외부 스크립트는 Turnstile만 허용한다.
- 메일은 당분간 아침 메일 Gmail로 보낸다. 보낸 사람 주소는 설정값(`KUMONIJI_MAIL_FROM`)이라 도메인을 사면 바꾼다(사용자 결정).

## 배제한 대안

- **별도 인증 서비스(기존 suvisdev auth 파드)**: 사용자 DB와 운영이 섞이고, 쿠모니지만 따로 배포·폐기하기 어렵다.
- **ORM·alembic**: 표 9개에 비해 무겁다.
- **Redis로 시도 제한**: SECURITY 12에 걸리고, 운영할 것이 하나 더 는다.
- **같은 이메일 자동 병합**: 남의 주소로 구글 계정을 만든 사람이 기존 계정을 가져갈 수 있다(SECURITY 10).
- **CanvasKit CDN(gstatic) 유지**: 복구 화면에 외부 스크립트가 실린다(SECURITY 5 "복구 화면에 외부 리소스 금지").

## 결과·확인

- 검증 기록은 `kumoniji/_docs/security-verification.md`에 있다. 서버 테스트 213, 앱 테스트 28, 실브라우저 시험을 거쳤다.
- 남은 일은 Turnstile 키(사용자 작업)와, 휴대폰 앱의 토큰 보관·구글 로그인(안드로이드 출시 전)이다.
