# ADR-0007. 기준 이미지 digest 고정, 집 안 동기화는 내부 IP

> **상태: 확정 · 2026-11-06**

## 문제

11-05 배포(run 42035158303)가 40분 제한에 걸려 취소됐다. 기록을 보면 빌드 6.4분, push 약 30분, 이후 롤아웃 중 취소다.

- `python:3.13-slim`을 태그로만 지정해서 원본 digest가 `ae14…`에서 `d0a9…`로 바뀌자 전체 레이어가 다시 빌드됐다.
- 큰 레이어를 같은 집인데도 Tailscale 중계(tok)로 올렸다. 11-06 실측은 중계 2.7MB/s, 내부 IP 34.4MB/s다.

## 결정

- `suvisdev/Dockerfile`의 기준 이미지를 digest로 고정한다.
- `sync-standby.sh`는 내부 IP로 SSH가 되면 그쪽을 쓰고, 아니면 Tailscale을 쓴다.
- 배포 잡 제한을 60분으로 올린다. 집 밖 최악 합계가 59분이기 때문이다.

## 배제한 대안

- 제한만 늘리기: 원인이 남아 배포가 계속 느리다.
- `STANDBY_HOST`를 내부 IP로 고정: 집 밖에서 동기화가 실패한다.
- Tailscale 직결 복구: 비용은 없지만 WSL·공유기 조건을 더 조사해야 한다. 내부 IP로 같은 문제가 먼저 풀린다.

## 결과·확인

- 기준 이미지 보안 갱신이 자동으로 들어오지 않는다. 올릴 때 digest를 직접 바꾼다.
- 집 밖 push 30분은 그대로이고, 집컴 롤아웃(HDD)도 줄지 않는다.
