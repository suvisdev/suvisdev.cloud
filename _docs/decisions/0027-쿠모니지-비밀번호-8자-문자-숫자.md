# ADR-0027: 쿠모니지 비밀번호는 8자 이상, 문자와 숫자를 섞는다

상태: 확정 (2026-11-27, 사용자 결정)

## 문제

계정 작업(11-21, 계획 B) 때 비밀번호를 15자 이상, 조합 규칙 없음(긴 문장 권장)으로 정했다. 게임 앱 사용자에게는 15자가 길고, 흔한 앱의 '8자 이상 + 문자·숫자'보다 낯설다.

## 결정

- 8자 이상, 128자(512바이트) 이하. 문자(한글 포함)와 숫자가 둘 다 있어야 한다. 아니면 `password_weak`.
- 그대로 두는 것: 유출 비밀번호 거부(HIBP, 조회 장애 땐 로컬 목록 또는 보류), 이메일·닉네임과 같으면 거부, argon2id, 로그인 시도 제한·캡차, 선택 2단계 인증.
- 이미 만든 계정의 비밀번호는 바꾸라고 하지 않는다(규칙은 새로 정하거나 바꿀 때만).

## 배제한 대안

- 15자 유지: 더 강하지만 사용자가 게임 앱엔 길다고 판단했다.
- 특수문자까지 강제: 사용자가 정한 범위 밖이고, 조합 규칙을 늘릴수록 '1!'을 끝에 붙이는 식의 예측 가능한 비밀번호가 늘어난다.

## 결과·확인

- 짧아진 만큼 추측 공격에 약해진다. 유출 목록 거부와 로그인 시도 제한이 이를 받친다.
- 서버 `accounts/passwords.py`(MIN 8 + weak), 앱 안내·오류 문구 4개 언어. 테스트: 7자 short, 8자 문자+숫자 통과, 문자만·숫자만 weak, 한글+숫자 통과.
