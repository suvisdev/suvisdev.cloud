# ADR-0005. PR 여부를 묻지 않는 자동 마무리

> **상태: 확정 · 2026-11-06** · 2026-10-20 "요청 시에만 커밋" 규칙을 대체
> 관련: ADR-0004

## 문제

정상 경로에서도 PR·리뷰 여부를 매번 물어 왕복이 늘었다.

## 결정

- 코드·설정 작업은 검증 → Codex 리뷰 → 커밋 → PR → CI → 머지까지 묻지 않고 진행한다.
- Codex 지적은 Claude와 Codex가 주고받아 OK까지 고친다.
- 보고는 Codex가 답이 없을 때와 변경 완료 때 한다.
- 예외: 새 환경 변수·DB 마이그레이션 등 선행 작업이 필요한 PR은 머지 전에 알린다. main 머지가 곧 운영 배포이기 때문이다. 운영 쓰기(DB·`.env`·서버 끄기·켜기)도 계속 허락을 받는다.

## 배제한 대안

- 머지 전 매번 확인: 사용자가 원하지 않았다.
- 예외 없이 전부 자동: 마이그레이션 없이 배포되면 API가 500을 낸다(인수인계 11-06).

## 결과·확인

- PR #235, #236을 이 절차로 머지했다.
