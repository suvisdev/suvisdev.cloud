# ADR-0020: 작업 일지는 앱별로 따로 쓴다

상태: 확정 (2026-11-21, 사용자 결정)

## 문제

- 쿠모니지(타일 게임) 기록이 "그 외 전부"인 `WORK_LOG_MAINPAGE.md`에 메인 사이트·인프라 기록과 섞여 들어갔다. 11-18~11-21 나흘치만으로 이 파일 맨 위 200줄 가까이를 차지해, 메인 사이트 기록을 찾기 어려워졌다.

## 결정

- **앱(제품)마다 워크로그 파일을 따로 둔다.** 이름은 `_docs/WORK_LOG_<앱>.md`.
- 지금 파일: `WORK_LOG_MOVA.md`(mova), `WORK_LOG_GILDLE.md`(gildle), `WORK_LOG_KUMONIJI.md`(쿠모니지, 이날 신설), `WORK_LOG_MAINPAGE.md`(메인 사이트·어드민·인증·인프라 등 특정 앱에 속하지 않는 것).
- **새 앱을 시작하면 첫 작업 날 그 앱의 파일을 새로 만든다**(예: 러시안룰렛 게임). MAINPAGE에 먼저 쌓았다가 나중에 옮기지 않는다.
- 한 세션에서 여러 앱을 건드렸으면 각 앱 파일에 그 앱 몫만 적는다.
- 쿠모니지의 11-18~11-21 기록은 MAINPAGE에서 새 파일로 옮겼고, MAINPAGE의 11-21 항목에는 옮겼다는 한 줄만 남겼다.

## 배제한 대안

- **MAINPAGE에 계속 쌓고 제목에 앱 이름만 붙이기**: 파일이 계속 길어지고, 앱 하나의 흐름을 따라 읽기 어렵다.
- **앱 폴더 안(`kumoniji/_docs/`)에 두기**: 다른 워크로그가 모두 `_docs/`에 있어 찾는 곳이 갈라진다. 세션 마무리 규칙(루트 CLAUDE.md)도 `_docs/WORK_LOG_*`를 기준으로 한다.

## 결과·확인

- 루트 `CLAUDE.md` "작업 일지" 표에 쿠모니지 파일과 새 앱 규칙을 추가했다.
