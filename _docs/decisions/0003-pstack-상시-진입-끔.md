# ADR-0003. pstack은 필요한 구간에만 쓴다

> **상태: 확정 · 2026-11-06**
> 관련: ADR-0002 · ADR-0005

## 문제

pstack 기본 설정은 세션마다 `poteto-mode` 진입을 강제한다. 작은 수정에도 재현·검증 절차가 돌아 시간과 토큰이 늘고, 서브에이전트 기본 사용 지침이 저장소 규칙과 부딪힌다. 사용자가 본 영상도 "항상 쓸 필요는 없다"고 설명한다.

## 결정

- `~/.claude/pstack-models.md`의 `session hook: off`로 상시 진입을 끈다.
- 라우터가 구간에 맞는 개별 스킬만 연결한다. `poteto-mode`는 사용자가 "포테이토 모드"라고 말할 때 쓴다.

## 배제한 대안

- 상시 진입 유지: 위 비용 때문에 버렸다.
- 설치하지 않기: 원칙 스킬과 `blast-radius` 등은 쓸모가 있다.

## 결과·확인

- 새 세션에서 원칙 스킬, `poteto-mode`, `pstack:poteto-agent` 호출을 확인했다.
- 해설 영상은 원본 기준으로 "대부분 모델 호출이 막혀 있다"고 설명하지만, 설치판(`michael-denyer/pstack-claude`)은 frontmatter에 그 설정을 쓴 스킬이 0개다.
