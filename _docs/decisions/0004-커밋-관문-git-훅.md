# ADR-0004. 커밋·푸시 관문은 git 훅으로 판정

> **상태: 확정 · 2026-11-06**
> 관련: ADR-0005

## 문제

"Codex OK 전에 커밋 금지"가 문장뿐이라 빠뜨릴 수 있었다. 처음에는 PreToolUse에서 명령 문자열을 정규식으로 해석했는데, Codex 리뷰마다 파일 지정 커밋, 복합 명령, 앞 공백 같은 새 우회가 나왔다.

## 결정

- 커밋과 main 푸시는 `.claude/githooks`가 판정한다. git이 넘긴 실제 내용을 보므로 명령 해석이 필요 없다.
- `gh pr merge`만 git 훅이 닿지 않아 따옴표를 지키는 토큰 파서로 찾고, 승인·CI·선행 작업을 확인한 뒤 `--match-head-commit`으로 판정 커밋에 고정한다.
- 승인은 커밋 해시가 아니라 코드 diff 해시에 묶는다. `_docs/`는 제외한다.
- Claude Code 실행(`CLAUDECODE=1`)에만 걸린다.

## 배제한 대안

- 정규식 계속 보강: 전제가 틀려 빈틈이 계속 나왔다.
- GitHub main 보호 규칙: 현재 쓰지 않기로 한 방침이다.

## 결과·확인

- 실제 저장소 임시 worktree에서 미승인 커밋 차단을 확인했다.
- 실수 방지 장치이며 보안 경계가 아니다. Bash로만 고친 파일은 자동 마무리 추적에서 빠진다.
