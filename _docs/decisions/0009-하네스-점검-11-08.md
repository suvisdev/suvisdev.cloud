# ADR-0009: 하네스 점검 — 드리프트 감지, 아키텍처 계약 확대, 로컬 의도 판단 제거

상태: 확정 (2026-11-08, Codex와 검토)

## 문제

- 메인 폴더가 `feat/deolmi-app`(PR #207, 열림)에 머물러 origin/main보다 57커밋 뒤였다. 세션이 읽는 `CLAUDE.md`에는 자동 마무리 절이 없었고, 훅은 손으로 복사해 둔 구판 `codex_gate.py`를 불렀다. 문서와 훅이 서로 다른 절차를 말했다.
- 헥사고날·클린 규칙 중 도메인 순수성 계약은 4개 앱에만 있었고, "유스케이스는 outbound 어댑터를 직접 쓰지 않는다"는 계약이 아예 없었다(실측 위반 9쌍).
- 스킬 라우터의 로컬 7.8B 의도 판단이 하루에 오탐 3건을 냈다. 노트북 단독(ADR-0008) 이후에는 운영 채팅과 같은 GPU를 쓴다.
- `protect-files.sh`는 연결되지 않은 채 남아 있었다. "커밋" 단어 훅은 자동 마무리 이후 거의 걸리지 않았다.

## 결정

- SessionStart의 `git pull`을 `harness_drift.py`로 바꾼다. 하네스 파일이 origin/main과 다르면 세션에 origin/main 판을 따르라고 알린다. 파일은 덮어쓰지 않는다.
- import-linter: 도메인 순수성을 `*.domain` 와일드카드 한 계약으로 묶는다. `app-no-outbound`(직접 import만, 기존 9쌍은 줄이기만 하는 예외)를 추가하고, auth·shared 계약에 news를 넣는다. 강제 목록은 `.claude/rules/backend-architecture.md`.
- 스킬 라우터의 모델 판단(ADR-0002의 7.8B 부분)을 뺀다. 규칙에 안 걸린 요청은 판단하지 않는다.
- `protect-files.sh`와 "커밋" 단어 훅을 지운다.

## 배제한 대안

- 메인 폴더를 main으로 전환: 10-20 사용자 결정과 충돌한다. 또 운영 파드가 이 폴더의 데이터를 마운트한다.
- origin/main을 `feat/deolmi-app`에 머지: 5개 파일이 충돌한다. 열린 PR #207을 사실상 재작업하게 된다.
- 세션을 worktree에서 시작(Codex 1안): 자동 메모리 경로가 폴더 경로에 묶여 있고, 운영 `.env`가 메인 폴더에만 있다.
- SessionStart에서 하네스 파일을 자동으로 덮어쓰기: 기능 브랜치가 더러워진다(Codex 반대).
- `protect-files.sh` 연결: 부분 문자열 매칭이라 `.env.example`까지 막고 Bash 수정은 못 막는다.
- `fastapi`·`sqlalchemy` 금지 계약: 외부 패키지 그래프가 필요해 기존 계약 영향을 따로 봐야 한다. 보류.
- 새 환경 변수 누락 검사(PREREQ 확장): 운영 선행 작업 판정과 문서 누락 검사는 분리해야 한다(Codex). 보류.

## 결과·확인

- 위반 탐침: `viewer.domain`→outbound, `dispatch.app`→outbound를 심으면 두 계약이 BROKEN이고, `app`→inbound는 통과한다. 탐침은 지웠다.
- 메인 폴더에서 `harness_drift.py`를 돌리면 다른 4개 파일을 짚는다. 하네스 시험 59개가 통과한다.
- ADR-0002는 모델 판단 부분이 이 결정으로 대체됐다.

## 후속 (11-10)

- 보류했던 두 건을 했다. `fastapi`·`starlette`·`sqlalchemy` 금지 계약(`core-no-frameworks`)은 `include_external_packages`를 켜고 기존 계약 결과가 같은지 확인했다.
- 새 환경 변수 누락 검사는 PREREQ와 분리해 CI 단계(`check_env_drift.py --code`)로 뒀다. 기존 누락 39개는 줄이기만 하는 명단이다. 한 번에 문서화하는 안은 `.env.example` 변경으로 머지가 선행 확인에 걸려 버렸다.
- `app-no-outbound` 예외 9쌍은 포트·주입으로 모두 지웠다.

## 후속 (같은 날)

- 사용자가 "하네스를 기반으로 돌아갈 수 있게 정리"를 요청해, 위에서 배제했던 **메인 폴더 main 전환**을 했다. 10-20 결정을 사용자가 바꾼 것이다. `feat/deolmi-app`은 `~/projects/wt-deolmi` worktree로 옮겼다.
- 운영 영향은 없다. 파드가 마운트하는 데이터와 lora 코드는 두 브랜치에서 같았다. 전환 뒤 드리프트 0, healthz·JWKS·lora 200을 확인했다. 비켜 둔 사본과 덜미 `.pyc` 캐시는 `~/harness-backup-switch-1922`에 있다.
