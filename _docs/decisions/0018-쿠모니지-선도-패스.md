# ADR-0018: 쿠모니지는 선도 패스할 수 있다

상태: 확정 (2026-11-21, 사용자 결정)

## 문제

- 멀티는 차례마다 20초, 넘기면 자동 패스로 정했다. 규칙 v4는 "선은 패스할 수 없다"라서 선 차례 시간 초과를 처리할 수 없었다(기획 초안은 "가장 약한 싱글 자동").

## 결정

- **선도 패스할 수 있다.** 바닥은 빈 채로 다음 사람이 선이 된다. 선의 패스는 바퀴 패스 수에 넣지 않는다(가져갈 바퀴가 없음). 꽃잎·보너스 변화 없음.
- 싱글·멀티 같은 규칙. 봇은 선일 때 패스하지 않는다.
- 멀티 20초 시간 초과는 선이어도 자동 패스.

## 배제한 대안

- 선 시간 초과 때 가장 약한 싱글 자동(기획 초안): 규칙은 안 바뀌지만 사용자가 패스를 택함.
- 멀티에서만 선 패스 허용: 규칙이 모드마다 달라져 하네스가 둘이 된다.
