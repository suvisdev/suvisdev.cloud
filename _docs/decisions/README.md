# 결정 기록 (ADR)

왜 그렇게 정했는지와 왜 다른 안을 버렸는지를 남긴다. 작업 일지가 "그날 있었던 일"이라면, 이 폴더는 "지금도 유효한 결정과 그 이유"다.

## 언제 쓰나

- 되돌리기 어렵거나 다음 작업의 방향을 정하는 결정, 대안을 버린 결정, 사용자가 정한 운영 방침.
- 쓰지 않는 것: 버그 수정 내용, 그날의 작업 내역(`WORK_LOG_*.md`), 실패와 극복(`LESSONS.md`).

## 규칙

- 파일 이름은 `NNNN-짧은-제목.md`, 번호는 이어서 붙인다.
- 지난 ADR은 고치지 않는다. 결정이 바뀌면 새 ADR을 쓰고 "무엇을 뒤집는지"를 적은 뒤, 옛 ADR의 상태 줄만 "개정됨 → ADR-NNNN"으로 바꾼다.
- 수치는 실제로 잰 것만 쓰고, 추정이면 추정이라고 적는다.
- 형식: 상태 줄, `## 문제`, `## 결정`, `## 배제한 대안`, `## 결과·확인`.
