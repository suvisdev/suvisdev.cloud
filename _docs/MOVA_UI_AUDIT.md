원본은 2026-08-05 전수 감사(`suvis/app/mova/**`·`components/mova/**`·`lib/mova-*`
정적 코드 + EC2 실 DB 대조)였다. **2026-08-09~10에 잔여 항목이 전부 처리되어

(2) 의도적으로 남긴 항목만 적는다.

## 의도적으로 남긴 것

| # | 항목 | 왜 남겼나 |
|---|------|-----------|
| 3-d | **번호 페이지네이션 없음** | 현재는 `hasMore` + "더 보기" 오프셋 누적 방식. 결함이 아니라 UX 선택지 — 바꿀지는 별도 결정 사항 |

> **1-d 프로필 이미지 업로드는 2026-08-10에 종결됐다.** 08-09에 "S3 미설정으로
> 보류"로 적었지만 **그 전제가 틀렸다** — 네 키가 로컬·EC2 `.env`에 이미 다
> 있었고 EC2에서 `Tank.list_buckets()`가 실제 버킷을 반환했다. 진짜 막고 있던 건
> 설정이 아니라 코드(컬럼·엔드포인트·UI 부재)였다. 자세한 경위: WORK_LOG 2026-08-10.

## §5 데이터 공백 — 해소 결과

2026-08-07 감사 시점엔 세 필드가 전부 0/2014였다(그래서 §3-b 플랫폼 필터가
`disabled`였고 §4-a 유사 영화를 붙일 수 없었다). 2026-08-10 프로덕션 백필 결과:

| 필드 | 결과 | 비고 |
|------|------|------|
| `age_rating` | 1538 / 2014 | TMDB에 KR 등급이 없는 영화가 있어 100%가 안 된다(스크립트가 `empty=289`로 구분 보고) — **완료** |
| `platforms` | 1510 / 2014 | 위와 같은 이유 — **완료** |
| `trailer_key` | 1877 / 2014 | 유튜브 트레일러가 없는 영화 `empty=113` — **완료** |
| `embedding` | **962 / 2014** | **미완** — Gemini 무료 티어 임베딩 **하루 1000건** 한도에 걸려 중단(`succeeded=959 failed=1052`) |

> **§4-a 유사 영화는 데이터가 아직 절반이다.** 원본 영화에 임베딩이 없으면
> `find_similar_movies()`가 None을 반환해 상세 페이지의 "비슷한 영화" 섹션이
> 아예 안 뜬다 — 지금은 962편에서만 보인다. 회귀가 아니라 백필 미완이고,
> 스크립트가 `embedding IS NULL`만 대상으로 잡아 idempotent하므로 날짜가 바뀌면
> 재실행으로 이어진다(남은 약 1052편 → 하루 한도상 이틀).
> 추적: PROGRESS.md 신규 1-b순위.

`users.preferred_genres`는 2026-08-07에 편집 UI(마이페이지)·온보딩 카드(홈)가
붙어 **사용자가 고르면 채워지는** 상태다. 수치가 낮은 건 경로가 없어서가 아니다.

`collection_id`(44/2014)는 컬렉션 5개 시드분이며, 큐레이션 확장은
PROGRESS.md 백로그(영화-컬렉션 배정 API/CLI) 소관이다.
