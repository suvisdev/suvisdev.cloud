## 6. 기존 백로그와의 대응 + 착수 우선순위 제안

- `platforms`·`age_rating` 백필 → **PROGRESS.md 6순위**로 이미 등록됨
- 컬렉션 큐레이션 확장 → **8순위**
- **그 외 §1~§4는 백로그에 없는 신규 건**이다.

착수 순서 제안(순수 의견, 결정은 별도):

1. **§1-c·1-e 마이페이지 삭제 기능** — 찜 삭제는 기존 API 재사용이라 프론트만,
   리뷰 삭제는 DELETE 엔드포인트 신설이 필요하다.
2. **§5 `platforms`/`age_rating` 백필**(=6순위) — 채우면 §3-b·§4-c가 코드 변경
   거의 없이 함께 살아난다(UI가 이미 배선돼 있고 잠가만 둔 상태).
3. **§4-a 유사 영화** — `movies.embedding` 백필이 선행이라 비용이 가장 크고,
   임베딩 백엔드 결정(hub_knowledge 재임베딩 이슈와 같은 선상)이 먼저다.
